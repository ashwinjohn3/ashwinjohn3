Software engineer with a track record building large-scale distributed systems, cloud-native infrastructure, and GenAI-powered tooling — shipping across multi-region fault-tolerant platforms serving millions of customers and enterprise security products backed by LLMs.

- **Cloud-Native Infrastructure** — ECS Fargate, Lambda, Step Functions, CloudFormation/CDK across GovCloud and air-gapped partitions
- **GenAI & Agent Engineering** — Bedrock AgentCore, Claude Code / kiro-cli harnesses, autonomous plan-review-execute loops
- **Backend APIs & Security** — Smithy/OpenAPI service design, IAM/Identity Center middleware, event-driven serverless streaming (3M+ events/day)
